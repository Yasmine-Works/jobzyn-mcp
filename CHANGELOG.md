# Changelog

## 0.1.1 — 2026-09-15

- Refine public documentation and package contents.
- Update version-pinned installation examples.

## 0.1.0 — 2026-09-15

- Expose all five documented JobZyn API operations as MCP tools.
- Provide an npm CLI with stdio as its default transport for Claude Desktop, Codex, and other MCP clients.
- Preserve all documented job fields, custom JSON fields, candidate pagination, and date filters.
- Include optional authenticated Streamable HTTP support; no hosted service is offered.
- Validate input, encode external job IDs, limit response size, redact API-key echoes, and report partial failures.
- Provide local credential handling, a read-only live-test helper, and a release package verifier.
- Include client examples, npm release instructions, and version-pinned installation configurations.
